# Expense Tracker App

A React-based Expense Tracker application built while learning full-stack development.

## Features

- Add expenses
- Render expense list dynamically
- Controlled form inputs using React state
- Component-based structure
- Basic responsive UI

## Tech Stack

- React
- JavaScript
- CSS
- Vite

## Learning Goals

This project is being built to practice:

- React fundamentals
- State management with `useState`
- Controlled inputs
- Props and component communication
- CRUD operations
- Full-stack MERN workflow

## Project Status

Currently in development.

Planned features:

- Delete expense
- Edit expense
- Filters and categories
- Local storage
- Backend with Node.js + Express
- MongoDB integration
- Authentication
- Deployment

## Installation

```bash
npm install
npm run dev
```
