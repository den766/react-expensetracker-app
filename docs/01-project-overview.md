# Expense Tracker

## Project Overview

Expense Tracker is a portfolio project that I'm building alongside my structured MERN learning roadmap. Instead of creating many small tutorial projects, I chose to continuously improve a single real-world application by adding new features as I learn new concepts.

The application allows users to manage their personal expenses, organize them efficiently, monitor monthly spending, and track budgets through a clean and responsive interface. Every feature in this project is implemented after understanding the underlying React and JavaScript concepts, making it both a learning project and an engineering project.

---

## Why I Built This Project

After completing a simple Notes application, I wanted to work on something more challenging that would expose me to real-world frontend problems.

An expense tracker naturally combines many common software engineering challenges, including:

- CRUD operations
- Searching
- Filtering
- Sorting
- Pagination
- Budget calculations
- Derived state
- Data persistence
- Responsive UI

Rather than building multiple isolated projects, I chose to invest my time into continuously improving one application and gradually transforming it into a complete MERN project.

---

## Engineering Approach

One of the biggest lessons from this project has been learning to think before writing code.

Instead of immediately implementing a feature, I first:

1. Plan the feature using Excalidraw.
2. Identify the required state.
3. Think through the data flow.
4. Break the feature into smaller implementation steps.
5. Implement incrementally.
6. Refactor when a better design becomes clear.

Alongside technical skills, this project has helped me develop engineering habits such as:

- Planning before coding
- Writing meaningful Git commit messages
- Building features incrementally
- Thinking in terms of state and data flow
- Refactoring instead of chasing perfection on the first attempt
